# Aditya.py — Developer Portfolio

A responsive portfolio website for Aditya Vishwakarma.

## Run locally
Open `index.html` in a browser. No build tools are required.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real professional email.
2. Add your latest resume PDF at `assets/Aditya_Vishwakarma_Resume.pdf`.
3. Check that every project folder is complete and that you can explain the code before describing it as completed work.
4. Update the Hotel Management System GitHub URL if the repository slug differs.
5. Upload the folder to GitHub Pages, Netlify or another static hosting service.
